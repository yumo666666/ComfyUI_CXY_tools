# ComfyUI_CXY_tools

本插件包含以下节点：

- ComfyUI_LLM_openai：文本/多图提示词拼接并调用 OpenAI 兼容接口
- Controlnet图预处理：深度/线稿/姿态预处理（自动下载缺失模型到插件内 models）
- 图比较：输入两张图，鼠标左右移动进行对比，支持反转层级
