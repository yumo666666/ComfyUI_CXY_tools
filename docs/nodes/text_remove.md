# 文本去除/替换

该节点用于对输入文本做“删除/替换”类清洗，常用于去空行、去特定标记、去多余分隔符等。

## 节点位置

`CXY工具/文字处理` → `文本去除/替换`

## 输入

- text：原始文本（支持多行）
- remove：需要删除的内容
- remove_mode：
  - 字面量删除：把 `remove` 里的内容当作普通文本删除
  - 正则删除：把 `remove` 里的内容当作正则表达式删除
- 解析转义：开启后会把 `\\n` / `\\t` / `\\r` / `\\\\` 等转义转为真实字符再执行删除
- 忽略大小写：对字面量/正则删除都生效
- 忽略空白项：当 `remove` 里包含空行/空项时是否忽略
- 多项模式：
  - 按行：`remove` 每行视为一个删除项
  - 按逗号：`remove` 以英文逗号分隔为多个删除项

## 输出

- text：处理后的文本

## 常见用法

### 1) 去空行

- remove 填：`\\n\\n`
- 解析转义：开启
- remove_mode：字面量删除

说明：这会把连续两个换行删除成一个换行，达到“压缩空行”的效果。

### 2) 去掉所有换行（变成一行）

- remove 填：`\\n`
- 解析转义：开启
- remove_mode：字面量删除

### 3) 正则去掉多余空白

- remove_mode：正则删除
- remove 填：`\\s+`
- 解析转义：开启

说明：会删除所有空白字符（空格/制表/换行等），请谨慎使用。
