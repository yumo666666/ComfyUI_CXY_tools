# 图片拼接（可选文字）

该节点用于把多张图片拼接成一张图，并可为每张图片添加一行文字说明。

## 节点位置

`CXY工具/图片处理` → `图片拼接（可选文字）`

## 特性说明

- 自动统一尺寸：以输入图片中“最大尺寸”的宽高作为目标尺寸，其它图片会等比缩放并居中裁剪到同尺寸，尽量减少留黑
- 背景图层：最终输出包含一个纯色背景底图，拼接好的图层会叠加在背景底图上
- 外边距：`内边距` 表示拼接图层到背景边缘的留白边距
- 可选文字：每张图片可填一段文字，文字可放在图片上方或下方，且水平居中显示

## 动态输入说明

- 图片输入端口会动态追加：连接 `image_1` 后出现 `image_2`，以此类推，并始终保留一个空的图片端口方便继续加图
- 每个 `image_n` 对应一个 `text_n` 文本输入（可为空）

## 输入

- image_1、image_2、image_3...：待拼接图片（动态端口）
- text_1、text_2、text_3...：对应图片的文字（可为空）
- 文字位置：文字在下方 / 文字在上方
- 排列：
  - 横向长条：1 行 N 列
  - 纵向长条：N 行 1 列
  - 正网格：自动 1x1、2x2、3x3...，从左到右从上到下填充
- 字号：文字大小
- 文字颜色：颜色选择器
- 背景颜色：整张输出图的底图颜色
- 内边距：拼接图层到背景边缘的留白边距
- 文字内边距：文字块内部留白（让文字不要贴边）

## 输出

- image：拼接后的图片（IMAGE）

## 使用建议

- 如果图片尺寸差异很大，建议优先使用“正网格”或“横向长条”并适当增大 `内边距`，让整体更规整
- 如果不需要文字，把 `text_n` 留空即可
