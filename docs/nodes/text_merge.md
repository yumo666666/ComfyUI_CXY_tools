# 文本合并

该节点用于把多路文本按顺序合并为一段文本，适合把多段提示词、分段脚本、列表项拼成最终文本。

## 节点位置

`CXY工具/文字处理` → `文本合并`

## 动态输入端口

该节点的文本输入端口会动态变化：

- 当 `text_1` 连接上后，会自动出现 `text_2`
- 当 `text_2` 连接上后，会自动出现 `text_3`
- 始终在最底部保留 1 个未连接的空端口，方便继续追加

## 输入

- separator：合并分隔符（默认 `\\n`）
- 解析转义：开启后会把 `\\n` / `\\t` / `\\r` / `\\\\` 等转义转为真实字符
- text_1、text_2、text_3...：动态追加的文本输入端口

## 输出

- text：合并后的文本

## 合并规则

- 只会合并“已连接”的 text_n
- 合并顺序按端口编号从小到大（从上到下）

## 示例

separator 填 `\\n\\n` 并开启解析转义，可以在每段文本之间插入一个空行。
