# 文本拆分

该节点用于按分隔符把一段文本切分为多段，并从多个输出端口依次输出。

## 节点位置

`CXY工具/文字处理` → `文本拆分`

## 动态输出端口

该节点的输出端口会按连接关系动态变化：

- 默认只有 `part_1`
- 当 `part_1` 被连接后，自动出现 `part_2`
- 当 `part_2` 被连接后，自动出现 `part_3`
- 以此类推，最多 16 路输出

## 输入

- text：待拆分文本（支持多行）
- separator：分隔符（默认 `\\n`）
- 解析转义：开启后会把 `\\n` / `\\t` / `\\r` / `\\\\` 等转义转为真实字符
- 越界策略：当输出口数量大于切分得到的段数时，额外输出如何处理：
  - 输出空字符串：输出为空
  - 重复最后一段：继续输出最后一段
  - 循环填充：从第一段开始循环输出

## 输出

- part_1 ~ part_16：按顺序输出的切分结果

## 常见用法

### 1) 按行拆分

separator 使用默认 `\\n` 并开启解析转义即可。

### 2) 按逗号拆分

separator 填 `,`，解析转义可关闭或开启均可。
